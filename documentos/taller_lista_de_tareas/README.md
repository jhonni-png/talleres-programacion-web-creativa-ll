# Lista de tareas interactiva con JavaScript

**Programación Web Creativa II** · Taller de Visual Studio Code

**Autores:** Jhonnier Santiago Giraldo y Darién Alonso

Aplicación web para registrar, completar y eliminar tareas. Las tareas se guardan en `localStorage`, por lo que siguen disponibles al recargar la página. Solo usa HTML, CSS y JavaScript nativo.

## Archivos

| Archivo | Descripción |
|---|---|
| `index.html` | Estructura: formulario, lista (`ul`) y mensaje de lista vacía |
| `styles.css` | Estilos: tarjeta centrada, tareas tachadas y botón rojo de eliminar |
| `script.js` | Lógica: agregar, completar, eliminar y persistir con `localStorage` |
| `Taller_Lista_de_Tareas_resuelto.docx` / `.pdf` | Informe del taller con código, explicación y evidencias |
| `capturas/` | Capturas de pantalla de la aplicación funcionando |

## Cómo ejecutarlo

Abrir `index.html` en el navegador (o con la extensión Live Server de VS Code). No requiere instalar nada.
